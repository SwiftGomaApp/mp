# swiftgoma-mp-auth

Authentication client for SwiftGoma apps: sign-up, login, session and automatic token renewal,
for React Native (Expo), Next.js and Vite.

> **Status: under development.** There is no working release yet; the first usable version will
> be 0.1.0. Nothing below is stable until then.

## Install

```bash
npm install swiftgoma-mp-auth axios
```
